# Empty State

**Rules** (cite as `ingredients-ui/components-empty-state--edge-cases#<slug>`):

- `very-long-heading` SHOULD — SHOULD truncate to 2 lines max
- `very-long-description` SHOULD — SHOULD truncate to 3 lines max with ellipsis
- `no-icon-provided` MUST — MUST still display heading (icon is visually expected but not structurally required)
- `container-too-small` SHOULD — Content SHOULD scale down gracefully, not clip

## Edge Cases

- **Very long heading**: SHOULD truncate to 2 lines max
- **Very long description**: SHOULD truncate to 3 lines max with ellipsis
- **No icon provided**: MUST still display heading (icon is visually expected but not structurally required)
- **Container too small**: Content SHOULD scale down gracefully, not clip
