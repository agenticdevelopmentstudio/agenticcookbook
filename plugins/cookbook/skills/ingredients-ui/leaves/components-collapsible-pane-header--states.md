# Collapsible Pane Header

## States

| State | Appearance |
|-------|-----------|
| Expanded | Chevron points down, pane content visible |
| Collapsed | Chevron points right, pane content hidden, header remains |
| Hover (macOS) | Subtle background highlight, pointer cursor |
