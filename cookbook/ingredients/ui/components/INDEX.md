# Component Ingredients

Reusable UI components that compose into larger panels and windows.

| File | Description |
|------|-------------|
| [ai-chat-control/](ai-chat-control/) | Compact inline chat control for multi-turn AI conversation with scrollable history and multi-provider support |
| [collapsible-pane-header/](collapsible-pane-header/) | Clickable header bar with disclosure chevron that collapses or expands a split view section |
| [color-profile/](color-profile/) | Named color palette with foreground, background, ANSI colors, and built-in presets for terminal and editor theming |
| [empty-state/](empty-state/) | Centered placeholder view shown when there is no content, with icon, heading, and optional action buttons |
| [git-status-indicator/](git-status-indicator/) | Git file status indicator with colored character badges, text labels, and priority-based directory rollup |
| [metadata-line/](metadata-line/) | Compact single-line label combining a leading icon with a text value for displaying metadata |
| [status-bar/](status-bar/) | Slim animated bar that slides in at the bottom of a view to indicate a background operation is in progress |
