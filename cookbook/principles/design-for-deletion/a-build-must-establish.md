
- `should-build-disposable-software`: the code is built to be disposable, or the work says why not
- `should-write-code-easy-to-throw-away`: the code can be removed without changes elsewhere in the system, or the work says why not
- `should-treat-lines-as-spent`: code that could be deleted is deleted, or the work says why not
- `should-not-abstract-prematurely-for-reuse`: no abstraction is introduced for reuse that has no current second use, or the work says why not
- `should-duplicate-rather-than-couple-when-in-doubt`: doubtful cases are duplicated rather than coupled, or the work says why not
- `should-delete-rules-that-no-longer-apply`: rules that no longer apply are deleted, not kept "just in case"
