
- `should-compose-from-small-focused-pieces`: behavior built up through a class hierarchy where small, focused pieces could be composed
- `should-use-inheritance-only-for-genuine-is-a`: a subclass whose relationship to its base is code reuse rather than a genuine "is-a"
- `should-prefer-protocols-over-base-classes`: shared behavior placed in a base class where a protocol, interface, or standalone function would carry it
- `should-wrap-rather-than-subclass`: behavior added by extending the inheritance chain where wrapping the existing type would do
