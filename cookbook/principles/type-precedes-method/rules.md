
- **should-classify-topic-type-before-searching**: SHOULD classify the topic's type (medical, technical, legal, financial, news, consumer, …) before searching.
- **should-select-authoritative-sources-by-type**: The type — not the user's wording or urgency — SHOULD select which sources count as authoritative.
- **should-set-evidence-bar-by-type**: The type SHOULD set the evidence bar: a treatment claim and a recipe claim are not held to the same standard.
- **should-not-carry-method-across-types**: A method that fits one type (web consensus for a recipe) is wrong for another (clinical trials for a treatment), and SHOULD NOT be carried over to it.
- **should-classify-each-claim-by-its-type**: When a topic spans types, SHOULD classify each claim by the type it asserts.
