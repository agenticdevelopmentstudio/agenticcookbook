
- **should-make-operations-safe-to-repeat**: User actions and system operations SHOULD be safe to repeat without duplicate side effects.
- **should-debounce-buttons-during-async**: Buttons SHOULD be debounced or disabled during async operations.
- **should-use-idempotency-keys**: API calls with side effects SHOULD use idempotency keys.
- **must-make-migrations-rerunnable**: Database migrations MUST be safe to run multiple times.
- **should-check-state-before-transitions**: Current state SHOULD be checked before applying state transitions.
