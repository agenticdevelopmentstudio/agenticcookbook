
- **should-document-the-journey**: SHOULD document the journey (thought graph, timeline, sources) so it can be resumed, revisited, and mined.
- **should-make-pauses-first-class**: SHOULD respect incubation by making pauses a first-class feature.
- **should-preserve-unchosen-branches**: A "parked" branch is not a failed idea — it is a resumable thread; the thought graph SHOULD preserve what was *not* chosen as richly as what was, enabling later mining.
- **should-preserve-all-past-work**: Tools SHOULD preserve all past work so users can return; showing only current state destroys the journey's accumulated value.
- **must-document-where-session-was-heading**: The facilitator's closing move MUST always be to document where the session was heading, so the next session can pick up from the right place without losing orientation.
