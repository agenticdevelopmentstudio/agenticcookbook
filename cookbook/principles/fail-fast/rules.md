
- **should-surface-invalid-state-at-origin**: Invalid state SHOULD be detected and surfaced immediately at the point of origin, not propagated silently.
- **should-assert-preconditions-in-debug**: SHOULD use assertions and preconditions in debug builds.
- **should-validate-inputs-at-boundaries**: SHOULD validate inputs at system boundaries.
- **should-return-typed-errors**: SHOULD return typed errors rather than swallowing exceptions.
- **must-not-use-empty-catch-blocks**: MUST NOT use empty catch blocks.
- **should-fail-gracefully-in-production-loudly-in-debug**: In production, SHOULD fail gracefully with clear messages; in debug, SHOULD fail loudly.
