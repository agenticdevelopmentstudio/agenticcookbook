# Window Recipes

Top-level window definitions that compose panels and components into complete interfaces.

| File | Description |
|------|-------------|
| [project-window/](project-window/) | IDE-style four-panel project window composing file tree, editor, terminal, and inspector in split views |
| [settings-window/](settings-window/) | Standard desktop settings/preferences window with sidebar categories and immediate-apply controls |
| [standalone-terminal-window/](standalone-terminal-window/) | Standalone terminal window with session sidebar and independent session manager for non-project terminal use |
| [workspace-window/](workspace-window/) | Two-pane workspace browser window for managing multiple projects with auto-discovery of project packages |
