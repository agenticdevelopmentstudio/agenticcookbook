- **ecosystem-correct-boundary**: The ecosystem pass MUST be fed the repos that actually establish the relationships, not an arbitrary subset. A boundary drawn too narrow produces a false "constellation of unrelated projects" conclusion — the model is right given the evidence it was handed and wrong about the real portfolio.
- **ecosystem-no-truncation**: Dossier trimming MUST NOT cut the trajectory/ecosystem section that describes how a project relates to the rest; the fix for a missed link is upstream, in selection and truncation, never in loosening the grounding rule.
