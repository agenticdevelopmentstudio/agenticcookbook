
- **should-use-single-project-msix**: SHOULD use the single-project MSIX packaging model.
- **must-declare-capabilities-minimally**: Capabilities MUST be declared minimally in `Package.appxmanifest`.
- **must-sign-with-trusted-certificate**: Packages MUST be signed with a trusted certificate for sideloading.
- **must-use-four-part-monotonic-version**: Version numbering MUST use `Major.Minor.Build.Revision`, monotonically increasing.
