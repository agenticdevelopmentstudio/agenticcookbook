
- `should-frame-rendering-as-architecture-selection`: The decision variable is **how much JavaScript reaches the client, and when**.

- `should-adopt-rsc-deliberately`: React Server Components (RSC) are the default for new high-performance **React** apps — but they are not a universal web requirement and apply only when you have already chosen React.
- `should-adopt-rsc-deliberately`: RSC adds **real complexity**: a server/client boundary you must reason about, serialization constraints on props, and **framework lock-in**.
- `should-pin-react-router-rsc-to-a-tested-release`: RSC is only usable **through a framework**. As of 2026: the **Next.js App Router is the mature, production-proven** RSC implementation.
