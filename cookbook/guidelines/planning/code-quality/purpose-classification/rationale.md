
- `should-keep-groups-purpose-coherent`, `should-split-incoherent-groups`: Scope groups with a clear, singular purpose are cohesive and independently understandable. If every file in a candidate scope group has the same primary purpose, the group is coherent.
- `should-split-mixed-files-along-fault-line`: A file that mixes UI and networking is a symptom — the fault line is between those two purposes.
