
- `should-look-for-existing-solution`: whether an existing solution was looked for before non-trivial functionality was built
- `must-check-existing-solutions-nearest-first`: whether the platform, current dependencies, own and shared codebases, and proven open source were checked, nearest first, before custom code was written
- `should-check-dependencies-before-adding`: whether current dependencies were checked before anything was added
- `should-search-ecosystem-for-prior-art`: whether the ecosystem was searched for prior art before non-trivial functionality was implemented
- `should-prefer-extending-existing-library`: whether an almost-fitting library already in use was extended or contributed to rather than paralleled
- `must-verify-candidate-package`: whether every added package is confirmed to exist, be actively maintained, and be genuinely used
- `should-not-install-unverified-ai-suggested-package`: whether any AI-suggested package name was installed without verification
- `must-weigh-dependency-against-building`: whether each new dependency was weighed against building it
