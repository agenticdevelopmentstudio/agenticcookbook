
- **must-not-break-at-2x-font-size**: Layouts MUST NOT break at 2x font size.
- **should-check-configuration-font-scale**: Layouts SHOULD check `Configuration.fontScale`.
- **should-test-with-large-font-settings**: Layouts SHOULD be tested with large font settings enabled.
- **should-use-sp-for-text-sizes**: Text sizes SHOULD be specified in sp, and fixed dp font sizes SHOULD be avoided.
- **should-use-scrollable-containers-for-expanding-text**: Scrollable containers SHOULD be used where text may expand.
