
- **should-use-mvvm-with-community-toolkit**: SHOULD use MVVM with [CommunityToolkit.Mvvm](https://learn.microsoft.com/en-us/dotnet/communitytoolkit/mvvm/) — source-generated `ObservableObject`, `RelayCommand`, and messaging.
- **should-use-navigationview-and-frame**: NavigationView + Frame SHOULD be used for page-level navigation.
- **should-put-navigation-service-in-viewmodel-layer**: A navigation service abstraction SHOULD live in the ViewModel layer.
- **must-not-manipulate-frame-from-code-behind**: Code-behind MUST NOT manipulate Frame directly.
- **should-scaffold-with-template-studio**: SHOULD use [Template Studio](https://github.com/microsoft/TemplateStudio) for project scaffolding with MVVM, navigation, and theming pre-wired.
