
- `should-use-dotnet-casing-consistently`: every symbol the build adds follows .NET's casing for its kind, or the code says why not
- `must-pascal-case-types-and-members`: every type, method, property, public field, constant and namespace the build adds is `PascalCase`
- `must-camel-case-parameters-and-locals`: every parameter and local the build adds is `camelCase`
- `must-underscore-camel-case-private-fields`: every private instance field the build adds is `_camelCase`
- `should-prefix-interfaces-with-i`: every interface the build adds starts with `I`, or the code says why not
- `must-suffix-async-methods`: every async method the build adds ends in `Async`
- `must-pascal-case-constants`: every constant the build adds is `PascalCase`
- `should-use-var-when-type-apparent`: the build uses `var` where the type is apparent from the right side, or the code says why not
