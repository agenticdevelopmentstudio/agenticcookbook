
- `should-use-dotnet-casing-consistently`: the code follows .NET's casing conventions consistently, or says why not
- `must-pascal-case-types-and-members`: every type, method, property, public field, constant and namespace is `PascalCase`
- `must-camel-case-parameters-and-locals`: every parameter and local variable is `camelCase`
- `must-underscore-camel-case-private-fields`: every private instance field is `_camelCase`
- `should-prefix-interfaces-with-i`: every interface carries the `I` prefix, or the code says why not
- `must-suffix-async-methods`: every async method ends in `Async`
- `must-pascal-case-constants`: every constant is `PascalCase`, none `SCREAMING_SNAKE_CASE`
- `should-use-var-when-type-apparent`: `var` is used wherever the type is apparent from the right side, or the code says why not
