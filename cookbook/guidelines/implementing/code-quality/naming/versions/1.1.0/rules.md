
- **should-use-dotnet-casing-consistently**: SHOULD use .NET's established casing conventions consistently: `PascalCase` for public symbols, `camelCase` for locals, and `_camelCase` for private fields.
- **must-pascal-case-types-and-members**: Types, methods, properties, public fields, constants, namespaces MUST use `PascalCase`.
- **must-camel-case-parameters-and-locals**: Parameters and local variables MUST use `camelCase`.
- **must-underscore-camel-case-private-fields**: Private instance fields MUST use `_camelCase` (underscore prefix).
- **should-prefix-interfaces-with-i**: Interfaces SHOULD take the `I` prefix (e.g., `IDisposable`).
- **must-suffix-async-methods**: Async methods MUST have the `Async` suffix (e.g., `SaveAsync`).
- **must-pascal-case-constants**: Constants MUST use `PascalCase`, not `SCREAMING_SNAKE_CASE`.
- **should-use-var-when-type-apparent**: SHOULD use `var` when the type is apparent from the right side of the assignment.
