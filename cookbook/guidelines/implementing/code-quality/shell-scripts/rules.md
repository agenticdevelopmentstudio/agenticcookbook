
- **must-main-only-call-functions**: Shell script `main()` functions MUST only call other functions — no inline logic.
- **must-keep-scripts-composable-and-testable**: Scripts MUST be kept composable and testable.
- **should-declare-shell-in-shebang**: You SHOULD declare the shell in the shebang and write to that shell's rules.
  - `#!/bin/sh` means POSIX `sh`: no arrays, no `[[ ]]`, no `local` assumptions, no process substitution.
- **should-use-bash-or-zsh-only-when-needed**: You SHOULD use `#!/usr/bin/env bash` (or zsh) only when you need those features, and then SHOULD NOT call the script with `sh`.
- **should-use-setopt-independent-forms**: You SHOULD quote every expansion and use `setopt`-independent forms so the script behaves the same under either zsh or bash.
  - Zsh is not a superset of bash by default. Word splitting of an unquoted variable is off unless `SH_WORD_SPLIT` is set (it is on only in `sh` and `ksh` emulation), arrays are one-based unless `KSH_ARRAYS` is set, and a glob with no match is an error (`NOMATCH`) rather than the literal text.
- **must-not-depend-on-job-control**: A script does not need `set -m` job control and MUST NOT depend on it; it SHOULD start background work with `&` and collect it with `wait`, and MUST NOT rely on `fg` or `bg` in a script.
  - `set -m` turns on job control, which POSIX makes the default only for interactive shells.
- **should-check-important-commands-explicitly**: You SHOULD check the commands that matter explicitly with `|| exit` or an `if`, because `set -e` is not a general error handler.
  - It is ignored for pipeline elements other than the overall result, inside command substitutions' subshells, in the condition of `if`, `while`, `until` and `elif`, after `!`, and for every command of an AND-OR list except the last.
- **should-default-optional-values**: You SHOULD give optional values a default with `${name:-default}`.
  - `set -u` fails the expansion of an unset parameter (the special parameters `@` and `*` excepted).
- **should-test-for-pipefail-or-avoid-it**: Older `sh` implementations may lack `set -o pipefail`, so you SHOULD test for it or avoid it in `#!/bin/sh` scripts.
  - `set -o pipefail` exists in the current POSIX edition. The pipeline's status becomes that of the rightmost command that failed, using the setting in effect when the pipeline began.
- **should-quote-every-expansion**: You SHOULD quote every expansion: `"$var"`, `"$@"`.
  - Single quotes keep text literal; double quotes keep everything except `$`, backquote and backslash. The characters that need quoting to be literal are `& ; < > ( ) $` backquote, backslash, quotes, space, tab and newline.
- **must-not-eval-built-strings**: You MUST NOT build a command in a string and run it with `eval`.
- **should-trap-for-cleanup**: You SHOULD use `trap` for cleanup: `trap 'cleanup' EXIT` runs when the shell exits; trap `INT` and `TERM` too if the script must clean up on a signal.
  - A non-interactive shell cannot trap or reset a signal that was ignored on entry, `KILL` and `STOP` cannot be trapped, a subshell resets its traps to the default, and a trap action waits until the foreground command finishes.
- **should-time-limit-hanging-commands**: You SHOULD put a time limit on any command that can hang with `timeout [options] duration command [arg]...` (GNU coreutils), use `-k` to send a follow-up kill, and, since `timeout` is not part of POSIX and may be absent on macOS, check for it, or do the work in Python.
  - It exits 124 when the command timed out, 125 when `timeout` itself failed, 126 when the command could not be run, 127 when it was not found, and 137 when the command was killed.
