
- `must-main-only-call-functions`: every `main()` only calls other functions
- `must-keep-scripts-composable-and-testable`: each script is composable and testable
- `should-declare-shell-in-shebang`: every script's shebang names its shell and the script keeps to that shell's rules, or the script says why not
- `should-use-bash-or-zsh-only-when-needed`: a bash or zsh shebang appears only where its features are used, and such a script is never called with `sh`, or the script says why not
- `should-use-setopt-independent-forms`: the script behaves the same under zsh and bash, or says why not
- `must-not-depend-on-job-control`: no script depends on `set -m`, `fg` or `bg`, and background work uses `&` and `wait`, or the script says why not
- `should-check-important-commands-explicitly`: every command that matters is checked with `|| exit` or an `if`, not left to `set -e`, or the script says why not
- `should-default-optional-values`: every optional value has a `${name:-default}`, or the script says why not
- `should-test-for-pipefail-or-avoid-it`: `pipefail` in a `#!/bin/sh` script is tested for or absent, or the script says why not
- `should-quote-every-expansion`: every expansion is quoted, or the script says why not
- `must-not-eval-built-strings`: no command is built in a string and run with `eval`
- `should-trap-for-cleanup`: cleanup runs from a `trap` on `EXIT`, and on `INT` and `TERM` where needed, or the script says why not
- `should-time-limit-hanging-commands`: every command that can hang runs under `timeout`, its exit codes are handled, and `timeout`'s presence is checked, or the script says why not
- `should-declare-shell-in-shebang`: the shebang matches the syntax used (no bashisms under `sh`);
- `should-check-important-commands-explicitly`: `set -e` is not relied on in conditions, pipelines or substitutions;
- `should-default-optional-values`: `set -u` variables have defaults and `pipefail` is guarded;
- `should-quote-every-expansion`: expansions are quoted and nothing is `eval`ed;
