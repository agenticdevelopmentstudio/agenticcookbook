
- `must-implement-all-parts`, `must-not-silently-drop-request-parts`: Work presented as complete that is not is worse than work that is honestly reported as partial.
- `must-verify-before-reporting-complete`: "It should work" is not "it works."
- `must-distinguish-speculative-from-requested`, `should-name-what-yagni-skips`: YAGNI defers *speculative* generality, not *known, requested* requirements.
