
| Variable | Expands to |
|----------|-----------|
| `$ARGUMENTS` | Full argument string passed after `/skill-name` |
| `$0`, `$1`, ... `$N` | Positional arguments (0-based, space-separated) |
| `${CLAUDE_SESSION_ID}` | Current session ID |
| `${CLAUDE_SKILL_DIR}` | Absolute path to this skill's directory |
