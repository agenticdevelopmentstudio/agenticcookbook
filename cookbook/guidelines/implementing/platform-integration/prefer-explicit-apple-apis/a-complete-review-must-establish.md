
- `must-use-appkit-and-uikit`: whether all UI code uses AppKit on macOS and UIKit on iOS
- `swiftui-only-where-required`: whether SwiftUI appears only where Apple requires it (widgets, Live Activities, App Clips)
- `keep-swiftui-layer-thin`: whether each required SwiftUI layer is kept as thin as possible
- `pin-target-and-avoid-deprecated-apis`: whether required SwiftUI surfaces pin the minimum deployment target and avoid deprecated APIs
