
- `should-construct-what-each-test-needs`: each test constructs its own data
- `should-avoid-large-shared-fixture-files`: no test depends on a large shared fixture file
- `should-use-builders-or-factories-for-complex-objects`: complex test objects come from builders or factories that take only the fields the test cares about
- `should-use-property-based-generators-for-coverage`: comprehensive input coverage uses property-based generators
- `should-use-inline-literals-for-simple-cases`: simple cases use inline literals
- `must-keep-specific-data-visible-in-the-test`: every test's specific data is visible in the test itself
