
- **should-choose-pattern-by-content-and-task**: Work SHOULD choose the right pattern (list, table, cards or grid) for the content type and user task.
- **should-support-refresh-and-pagination-in-lists**: Lists SHOULD support pull-to-refresh and pagination for dynamic data.
- **must-make-tables-sortable**: Tables MUST be sortable by column.
- **should-consider-collapsing-tables-on-mobile**: On mobile, work SHOULD consider collapsing tables to cards or a detail-on-tap list.
- **should-make-each-card-one-tappable-unit**: Cards SHOULD each be a single tappable unit with one primary action.
- **should-maintain-grid-aspect-ratios**: Grids SHOULD maintain consistent aspect ratios.
- **should-sort-or-filter-ten-plus-items**: Collections of **10+ items** SHOULD provide sort and/or filter controls.
- **must-search-fifty-plus-items**: Collections of **50+ items** MUST include search.
