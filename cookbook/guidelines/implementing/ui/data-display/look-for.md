
- `should-choose-pattern-by-content-and-task`: a list, table, card or grid pattern that does not fit the content type and user task
- `should-support-refresh-and-pagination-in-lists`: a list of dynamic data without pull-to-refresh or pagination
- `must-make-tables-sortable`: a table whose columns cannot be sorted
- `should-consider-collapsing-tables-on-mobile`: a wide table shown unchanged on mobile with no cards or detail-on-tap alternative
- `should-make-each-card-one-tappable-unit`: a card with several tap targets or more than one primary action
- `should-maintain-grid-aspect-ratios`: grid items with inconsistent aspect ratios
- `should-sort-or-filter-ten-plus-items`: a collection that can hold 10 or more items without sort or filter controls
- `must-search-fifty-plus-items`: a collection that can hold 50 or more items without search
- `should-sort-or-filter-ten-plus-items`, `must-search-fifty-plus-items`: sort/filter at 10+ items, search at 50+
