
- `should-not-replace-text-with-icons`: whether any icon replaces text other than a universally understood symbol (play, pause, close, search)
- `should-use-native-icon-set-first`: whether the platform's native icon set is used first
- `must-label-action-icons`: whether every icon accompanying an action has a text label or accessible name
- `should-keep-icon-size-and-weight-consistent`: whether icon size and weight are consistent across the UI
- `should-not-mix-outlined-and-filled-without-intention`: whether every mix of outlined and filled styles carries an intended meaning
- `should-meet-minimum-icon-size`: whether every icon meets 16x16pt when decorative and 24x24pt when interactive
- `must-pair-state-icons-with-color-and-shape`: whether every icon conveying state (error, success, warning) is paired with color and shape
