
- `should-not-replace-text-with-icons`: an icon standing in place of a text label, unless it is a universally understood symbol (play, pause, close, search)
- `should-use-native-icon-set-first`: custom or third-party icons used where the platform's native set (SF Symbols, Material Symbols, Segoe Fluent Icons) has one
- `must-label-action-icons`: an icon on an action with neither a text label nor an accessible name
- `should-keep-icon-size-and-weight-consistent`: icons of differing size or weight across the UI
- `should-not-mix-outlined-and-filled-without-intention`: outlined and filled icon styles mixed with no meaning behind the mix (such as filled = selected, outlined = unselected)
- `should-meet-minimum-icon-size`: a decorative icon under 16x16pt, or an interactive icon under 24x24pt
- `must-pair-state-icons-with-color-and-shape`: an error, success or warning icon that conveys its state by color alone or by shape alone
