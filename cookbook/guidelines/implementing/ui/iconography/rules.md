
- **should-not-replace-text-with-icons**: Icons SHOULD supplement text and SHOULD NOT replace it (except for universally understood symbols like play, pause, close, and search).
- **should-use-native-icon-set-first**: The platform's native icon set SHOULD be used first (SF Symbols, Material Symbols, Segoe Fluent Icons).
- **must-label-action-icons**: All icons accompanying actions MUST have a text label or accessible name.
- **should-keep-icon-size-and-weight-consistent**: SHOULD maintain consistent size and weight across the UI.
- **should-not-mix-outlined-and-filled-without-intention**: SHOULD NOT mix outlined and filled styles without intention (e.g., filled = selected, outlined = unselected).
- **should-meet-minimum-icon-size**: Icons SHOULD be at least the minimum icon size: 16x16pt for decorative, 24x24pt for interactive (see Touch & Click Targets for the full hit area).
- **must-pair-state-icons-with-color-and-shape**: Icons conveying state (error, success, warning) MUST be paired with color AND shape — see Color section.
