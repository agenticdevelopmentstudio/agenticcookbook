
- **must-show-determinate-progress-when-total-known**: When the UI is waiting on an async task, **determinate progress** (progress bar with percentage) MUST be shown when total work is known.
- **must-show-indeterminate-progress-when-total-unknown**: When the UI is waiting on an async task, **indeterminate progress** (spinner, skeleton, shimmer) MUST be shown when total work is not known.
- **must-not-appear-frozen**: When the UI is waiting on an async task, the UI MUST NOT appear frozen or unresponsive.
