
# AppKit and UIKit patterns

Use AppKit and UIKit, not SwiftUI ([adc.guideline.implementing.platform-integration.prefer-explicit-apple-apis](cookbook:095b33a1-2835-4ed5-bf01-f1e492148819)) chooses the frameworks. This guideline covers how to use them: the patterns that every AppKit and UIKit screen depends on, and the mistakes that follow from fighting them.
