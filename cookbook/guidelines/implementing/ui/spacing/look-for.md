
- `should-use-4px-spatial-scale`: spacing that follows no consistent scale built on a 4px base unit (8px primary grid)
- `must-use-multiples-of-4`: a spacing, padding or margin value that is not a multiple of 4
- `should-avoid-arbitrary-values`: an arbitrary value such as 5px, 13px or 37px
- `should-reconsider-off-scale-values`: a value off the scale (4, 8, 12, 16, 24, 32, 48, 64) kept with no reason given
- `should-use-spacing-tokens`: CSS custom properties or design tokens for spacing on 4px scale (4/8/12/16/24/32/48/64);
- `should-avoid-arbitrary-values`: no arbitrary values in margin/padding/gap;
