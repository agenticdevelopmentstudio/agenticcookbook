
- `should-use-4px-spatial-scale`: spacing uses one scale based on a 4px base unit (8px primary grid), or the code says why not
- `must-use-multiples-of-4`: every spacing, padding and margin value is a multiple of 4
- `should-avoid-arbitrary-values`: no arbitrary value (5px, 13px, 37px) is used, or the code says why
- `should-reconsider-off-scale-values`: every value off the scale carries a reason it stays, or is replaced by a scale value
- `should-use-spacing-tokens`: every spacing value comes from a CSS custom property or design token on the 4px scale (4/8/12/16/24/32/48/64), or the code says why not
