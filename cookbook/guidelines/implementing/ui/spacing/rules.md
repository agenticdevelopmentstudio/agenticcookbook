
- **should-use-4px-spatial-scale**: SHOULD use a consistent spatial scale based on a **4px base unit** (8px primary grid).
- **must-use-multiples-of-4**: All spacing, padding, and margin values MUST be multiples of 4.
- **should-avoid-arbitrary-values**: Arbitrary values (5px, 13px, 37px) SHOULD be avoided.
- **should-reconsider-off-scale-values**: If a value isn't on the scale, SHOULD reconsider it.
- **should-use-spacing-tokens**: Spacing SHOULD be set through CSS custom properties or design tokens on the 4px scale (4/8/12/16/24/32/48/64).
