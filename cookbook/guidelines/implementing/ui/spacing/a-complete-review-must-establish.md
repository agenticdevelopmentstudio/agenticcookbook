
- `should-use-4px-spatial-scale`: whether spacing follows a consistent scale based on a 4px base unit
- `must-use-multiples-of-4`: whether every spacing, padding and margin value is a multiple of 4
- `should-avoid-arbitrary-values`: whether any arbitrary value (5px, 13px, 37px) is used
- `should-reconsider-off-scale-values`: whether every value off the scale was reconsidered
