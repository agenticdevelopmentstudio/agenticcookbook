
- `must-include-preview-declarations`: whether every UI component includes a preview declaration
- `should-cover-significant-states`: whether previews cover all significant states (default, loading, error, empty, populated)
- `must-include-swiftui-preview-blocks`: whether every SwiftUI view includes a `#Preview` block
- `should-verify-swiftui-previews-render`: whether verification confirmed the SwiftUI previews render without crashes
- `must-include-compose-preview-functions`: whether every Compose component includes an `@Preview` function
- `should-verify-compose-previews-compile`: whether verification confirmed the Compose preview functions compile
