
- **must-include-preview-declarations**: All UI components MUST include preview declarations for rapid visual verification during development.
- **should-cover-significant-states**: Previews SHOULD cover all significant states (default, loading, error, empty, populated).
- **must-include-swiftui-preview-blocks**: All SwiftUI views MUST include `#Preview` blocks.
- **should-verify-swiftui-previews-render**: Verification SHOULD include confirming SwiftUI previews render without crashes.
- **must-include-compose-preview-functions**: All Compose components MUST include `@Preview` functions.
- **should-verify-compose-previews-compile**: Verification SHOULD include confirming Compose preview functions compile.
