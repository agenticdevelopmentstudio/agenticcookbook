
- `should-use-semantic-color-tokens`: hard-coded hex values where a platform semantic color exists
- `should-limit-the-palette`: more than one primary/accent color, more than 1-2 neutral tones, or a rainbow UI
- `must-not-rely-on-color-alone`: a state change, error or status shown by color with no icon, shape, text or pattern
- `must-meet-contrast-minimums`: text or non-text UI components below the WCAG AA contrast minimums
- `must-work-in-light-and-dark`: a color that fails in the light or the dark theme
- `should-test-light-and-dark`: UI checked in only one theme
