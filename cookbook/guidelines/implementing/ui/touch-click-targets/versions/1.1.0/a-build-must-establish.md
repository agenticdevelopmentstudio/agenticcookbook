
- `must-size-targets-for-accurate-input`: every interactive element is large enough to tap or click accurately
- `should-defer-to-platform-hig-minimum`: every target meets its platform HIG minimum, or the code says why not
- `should-default-to-44x44`: where no platform HIG applies, every target is at least 44x44, or the code says why not
- `should-pad-hit-area-beyond-visual`: a visual element smaller than its target has its hit area padded to the target size
- `must-space-adjacent-targets-8px`: adjacent targets are at least 8px apart
- `should-give-inline-links-line-height`: inline text links have line height sufficient for comfortable tapping, or the code says why not
