
- **should-establish-importance-through-visual-weight**: SHOULD establish clear importance through size, weight, color, and spacing.
- **should-have-one-obvious-focal-point**: Every screen SHOULD have one obvious focal point — the primary action or content the user came for.
- **must-have-one-primary-action-per-screen**: **One primary action per screen** — there MUST be a single focal point; if everything is bold, nothing is bold
- **should-distinguish-headings-by-size-and-weight**: SHOULD use size and weight (not just color) to distinguish heading levels.
- **should-group-by-proximity**: SHOULD group related content with proximity and separate unrelated content with whitespace.
- **must-distinguish-interactive-elements**: Interactive elements MUST be visually distinguishable from static content
- **should-mute-disabled-elements**: Disabled elements SHOULD be visually muted but still discoverable
