
- `should-establish-importance-through-visual-weight`: elements of different importance given the same size, weight, color and spacing
- `should-have-one-obvious-focal-point`: a screen with no obvious focal point on the primary action or content
- `must-have-one-primary-action-per-screen`: a screen with more than one primary action, or with everything bold
- `should-distinguish-headings-by-size-and-weight`: heading levels told apart by color alone
- `should-group-by-proximity`: related content spread apart, or unrelated content with no whitespace between
- `must-distinguish-interactive-elements`: an interactive element that looks like static content
- `should-mute-disabled-elements`: a disabled element that is not muted, or is hidden rather than discoverable
