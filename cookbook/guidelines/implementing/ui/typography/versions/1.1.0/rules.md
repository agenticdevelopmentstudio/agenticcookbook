
- **must-use-platform-system-font**: The platform's system font MUST be used (see the platform system fonts list).
- **should-establish-type-scale-with-roles**: SHOULD establish a type scale with clear roles — SHOULD NOT invent sizes ad-hoc (don't invent sizes ad-hoc).
- **should-default-body-text-to-14-17pt**: Defaults when no design system exists — **Body text** SHOULD be 14-17pt (16px is the safest cross-platform default).
- **must-not-go-below-minimum-readable-size**: Defaults when no design system exists — **Minimum readable size**: 11-12pt for captions/labels, text MUST NOT be smaller.
- **should-set-body-line-height-1-4-to-1-5**: Defaults when no design system exists — **Line height** SHOULD be 1.4x-1.5x font size for body text.
- **should-use-platform-heading-scale**: Defaults when no design system exists — **Heading scale**: SHOULD use the platform's built-in type scale (Dynamic Type, Material type tokens, Fluent type ramp) rather than inventing sizes.
- **should-limit-font-weights-per-screen**: General principles — SHOULD limit to 2-3 font weights per screen (regular, medium/semibold, bold).
- **should-avoid-all-caps**: General principles — All-caps SHOULD be avoided for more than a few words — harms readability and screen reader experience.
- **should-keep-paragraph-width-45-75-characters**: General principles — **Paragraph width** SHOULD be 45-75 characters for comfortable reading.
