
- `must-use-platform-system-font`: a font other than the platform's system font
- `should-establish-type-scale-with-roles`: font sizes invented ad-hoc rather than drawn from a type scale with clear roles
- `should-default-body-text-to-14-17pt`: with no design system, body text outside 14-17pt
- `must-not-go-below-minimum-readable-size`: with no design system, text smaller than 11-12pt
- `should-set-body-line-height-1-4-to-1-5`: with no design system, body line height outside 1.4x-1.5x the font size
- `should-use-platform-heading-scale`: with no design system, heading sizes invented instead of taken from Dynamic Type, Material type tokens or the Fluent type ramp
- `should-limit-font-weights-per-screen`: more than 2-3 font weights on one screen
- `should-avoid-all-caps`: all-caps text longer than a few words
- `should-keep-paragraph-width-45-75-characters`: paragraphs wider or narrower than 45-75 characters
