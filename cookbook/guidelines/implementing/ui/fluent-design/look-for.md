
- `should-use-built-in-winui-controls`: custom or third-party controls where a built-in WinUI 3 control exists
- `must-not-custom-draw-standard-controls`: custom-drawn UI that reproduces what a standard control does
- `should-use-segoe-ui-variable`: text set in a font other than Segoe UI Variable
- `should-use-segoe-fluent-icons`: icons drawn from a set other than Segoe Fluent Icons
- `must-follow-windows-design-guidance`: layout, spacing or navigation that departs from Windows design guidance
