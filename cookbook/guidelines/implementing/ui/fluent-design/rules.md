
- **should-use-built-in-winui-controls**: Applications SHOULD use built-in WinUI 3 controls — they implement Fluent 2 natively.
- **must-not-custom-draw-standard-controls**: Applications MUST NOT custom-draw what a standard control can do.
- **should-use-segoe-ui-variable**: Typography SHOULD use Segoe UI Variable.
- **should-use-segoe-fluent-icons**: Icons SHOULD use Segoe Fluent Icons.
- **must-follow-windows-design-guidance**: Applications MUST follow [Windows design guidance](https://learn.microsoft.com/en-us/windows/apps/design/) for layout, spacing, and navigation patterns.
