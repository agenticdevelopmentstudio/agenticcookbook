## In Claude Code

The user's `CLAUDE.md` files and the repo's `.claude/rules/` outrank these
principles where they conflict. To read a full principle or guideline, run
`skill-router show <name> --host claude --model <your model ID>` and Read the
file on its `skill:` line. Your model ID is in your system prompt; never infer
it from tooling.
